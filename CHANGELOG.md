# Changelog

## 0.1.0 — 2026-10-16

### Added

- A referral-research skill that ranks a small shortlist by role relevance and supported professional evidence.
- Configurable alumni preferences with explicit treatment of campus, program, and uncertain evidence.
- Supplied-evidence mode and a fictional demo that can be tried without LinkedIn access.
- Personalized tone options and exact approval previews before any contact action.
- Codex installation instructions, UI metadata, and manual behavioral review cases.

### Limitations

- Live research depends on the user's supported Chrome connection; this package does not supply one.
- This is an instruction-only release. Approval behavior is not enforced by executable code.
- The fictional example establishes no live LinkedIn reliability or real referral outcome.
